01

Description

What the skill is for, and what it leaves alone.

The seed decides where to go. Your requirements decide everything else.

Picking “at random” in a model's head isn't random. It lands on the same favorites every time. The skill gets its randomness from the shell, then treats the result the way a designer treats a found object: as a brief to interpret, not a rule to obey.

Before anything is generated, the task is sorted into two lists. The seed only ever touches the second.

Fixed

  • Your stated requirements
  • Design systems, brand rules, existing tokens
  • Accessibility, correctness, real facts
  • Budget, platform rules, honesty

Open

  • Palette, type, composition, imagery
  • Architecture shape, data model, lead quality
  • Campaign angle, audience moment, format
  • Structure, point of view, name construction

02

Method

Four steps, the same in every domain.

Frame, roll, read, build.

  1. Frame

    Sort what's fixed from what's genuinely open. Usually three to six open choices.

  2. Roll

    A bundled script prints a random string with a digest of the patterns in it.

  3. Read

    Patterns become decisions: a digit sum becomes a hue, a run becomes a motif, digits pick from menus.

  4. Build

    Execute the direction with full craft, then check the result hasn't drifted back to the default.

Specimen, rolled in your browser

A simplified version of the digest the skill reads. Mint marks hex-like runs; underlines mark palindromes. The example readings are mechanical. The skill applies judgment on top.

04

Connecting fal

The fal MCP server is free. You pay only for the model runs you trigger.

Three steps to the full effect.

Step 1

Get a fal API key

Sign in at fal.ai, open fal.ai/dashboard/keys, choose Create Key, and copy it right away. You won't see it again.

Step 2

Add the fal MCP server to your agent

Replace YOUR_FAL_KEY with your key.

Run this in your terminal:

claude mcp add --transport http --scope user fal-ai \
  https://mcp.fal.ai/mcp \
  --header "Authorization: Bearer YOUR_FAL_KEY"

--scope user makes fal available in every project. Run /mcp inside Claude Code to check that fal-ai is connected.

Open or create ~/.cursor/mcp.json and add the server under mcpServers:

{
  "mcpServers": {
    "fal-ai": {
      "url": "https://mcp.fal.ai/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_FAL_KEY"
      }
    }
  }
}

Save, then check that fal-ai shows up in Cursor's MCP settings.

Open ~/.codeium/windsurf/mcp_config.json and add the server under mcpServers:

{
  "mcpServers": {
    "fal-ai": {
      "serverUrl": "https://mcp.fal.ai/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_FAL_KEY"
      }
    }
  }
}

Save, then enable fal-ai in Cascade's MCP settings.

No key needed. Open the fal plugin listing, install it, and connect your fal account when prompted. In the Codex CLI, use /plugins to find and install fal, then start a new session.

Any client that supports the Streamable HTTP transport and a custom authorization header can connect:

URL:    https://mcp.fal.ai/mcp
Header: Authorization: Bearer YOUR_FAL_KEY
Step 3

Start a new session and check it

Most agents only pick up a new server in a fresh session. Then ask:

Use fal to search for image generation models. Do not run a model.

If you get a list of models back, you're set. The skill finds the fal tools on its own from then on.

On cost. By default the skill uses the highest-quality model for each piece and doesn't stop to ask. Mention a budget in your prompt and it switches to pricing every model first, showing an estimate, and waiting for your yes.

Full setup docs: fal.ai/docs, MCP setup.

05

Installation

Open Agent Skills format. No plugin system required.

Install it once, use it everywhere.

Any agent, with the skills CLI

npx skills add bgarcia7/exploration

Add -g to install it for all your projects. The CLI needs Node 22 or newer.

Manually

Copy skills/exploration from the repository into your agent's skills folder, for example ~/.claude/skills/ for Claude Code.

Claude.ai or the Claude desktop app

Download exploration.zip from the latest release and upload it under Skills in Claude's settings. Code execution needs to be on.

06

Handling

Ask in plain words. The skill picks up open-ended requests on its own.

Ask for options, or ask to be surprised.

  • Landing page for my bike repair app, x3design · 3 variants
  • Surprise me with names for a tea subscriptionnaming
  • Three ways to do offline sync for this app, comparedarchitecture
  • Launch campaign ideas for our new pricingmarketing
  • Rewrite this intro, but try something I wouldn'tediting

Add a number like x3 for independent variants with a comparison and a recommendation. Ask for a re-roll when you want a genuinely new direction rather than a revision. When the direction is already decided, the skill stays out of the way.
